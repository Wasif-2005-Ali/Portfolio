# Wasif Ali — Portfolio

Personal portfolio of Wasif Ali, Full-Stack Developer.

**Live site:** https://wasif-ali.me

Built with Next.js 15, React 19, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Design

The design is adapted from Abdul Wahid's portfolio (abdulwahid.me), used with his
permission, with all content replaced by Wasif's own.
