# Wasif Ali — Full-Stack Developer

Personal portfolio of Wasif Ali, Computer Science undergraduate at Air University Kamra.

**Live site:** https://wasifportfolio-phi.vercel.app

## About

- **Home** — introduction and selected work
- **Projects** — 10 case studies with approach, evaluation, and limitations
- **Writing** — short notes on algorithms and data annotation
- **About** — experience, education, certificates, and live GitHub activity charts
- **CV** — print-ready CV with PDF download
- **Links & Contact** — profiles and a mailto contact form (no backend)

## Tech stack

Next.js 15 · React 19 · TypeScript · Tailwind CSS · Lucide icons · Deployed on Vercel

Design: Anton for display type, Archivo for body text, Instrument Serif italic for accent words, JetBrains Mono for labels and eyebrows.

## Run locally

```
npm install
npm run dev
```

Open http://localhost:3000. Production build:

```
npm run build
npm run start
```

## Project structure

```
app/          # routes: home, projects, writing, about, cv, contact, links
components/   # shared UI: header, footer, reveal, project cards
content/      # site content: profile, projects, articles (edit here)
public/       # images, icons, CV, and static assets
```

Content lives in `content/` — updating a project or article is a data edit, not a layout change.
